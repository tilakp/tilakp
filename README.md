## Hi there 👋

You will find some of my non-work related experiments ⚡ here. Most of them are small native macOS apps that solve one problem I kept running into.

### macOS apps

**[maclink](https://github.com/tilakp/maclink)** · Swift  
Press a hotkey in any app to capture a deep link to whatever you are looking at, whether that is a file, an email, or a web page. Paste the `maclink://` URL anywhere, and opening it later takes you back to that exact item in its original app. Includes Emacs org-mode integration.

**[bookdrop](https://github.com/tilakp/bookdrop)** · Rust  
Converts EPUB ebooks to PDF, TXT, HTML, or DOCX. The PDF path runs on a Rust engine with a bundled headless Chromium, so you keep full control of page size, margins, typography, and headers. Drag and drop, batch conversion, and history are built in.

**[aloud](https://github.com/tilakp/aloud)** · Swift  
Select text anywhere on macOS, press a hotkey, and hear it read aloud. It runs Kokoro TTS on device, so nothing goes to the cloud and there is no Python to install.

**[mac-prompt](https://github.com/tilakp/mac-prompt)** · Swift  
A teleprompter for macOS, written in SwiftUI. It scrolls your script smoothly and keeps the controls within reach, which suits presentations, recordings, and speeches.

**[SoundDeck](https://github.com/tilakp/SoundDeck)** · Swift  
A soundboard for macOS. Sounds play over each other instead of cutting off, each pad has its own volume, trim, and loop, and global hotkeys reach the deck from any app. You can send the audio to your speakers or into a call.

**[flip-clock](https://github.com/tilakp/flip-clock)** · Swift  
A retro flip clock built in SwiftUI. The digits scale to fill whatever window you give them, and the leaves fall and settle like the mechanical original. Alarms stay out of the way behind a control until you reach for them.

**[formzeit-screensaver](https://github.com/tilakp/formzeit-screensaver)** · Swift  
A Bauhaus-inspired analog clock screensaver. It is a native `.saver` bundle written in Swift, built without an Xcode project.

### Configs and older experiments

**[hammerspoon-dotfiles](https://github.com/tilakp/hammerspoon-dotfiles)** · Lua  
My Hammerspoon setup, driven by Caps Lock remapped to a hyper key. It pastes without formatting, connects AirPods, toggles the microphone, reports Wi-Fi changes in the menu bar, and shows a shortcut cheatsheet for the current app.

**[userscripts](https://github.com/tilakp/userscripts)** · JavaScript  
Small browser userscripts. The current one adds a Seattle Public Library search link to Amazon book pages, so you can borrow a book before you buy it.

**[gulp-responsive-email-workflow](https://github.com/tilakp/gulp-responsive-email-workflow)** · HTML  
A Gulp.js workflow for building and testing responsive HTML email templates locally. It handles CSS inlining and opens a browser preview.
